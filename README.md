## 🚀 Project Overview

A Java-based Real Estate Listing Portal designed to manage and display property listings. The application allows users to add properties, view available properties, search properties by location, and display property details such as price, type, area, and owner contact information.

---

## ✨ Features

- 🏠 Add new property listings
- 📋 View all property listings
- 🔍 Search properties by location
- 💰 Display property price
- 📐 Display property area
- 🏡 Display property type
- 📞 Display owner contact details
- 🚪 Exit the application
